LESSON 1

Introduction to Programming

Learn what programming means, why variables are used, how programming languages differ, and the key facts about C++ history.

Learning Objectives

  • Define programming and a program.
  • Explain how instructions are given to computers.
  • Explain variables and their purpose.
  • Distinguish high-level and low-level languages.
  • Identify the creator and important dates in C++ history.

1. What is Programming?

Programming is the process of writing instructions that tell a computer what to do. A program is a set of instructions that a computer can execute to perform a task.

Humans describe a problem and create instructions. Those instructions are written as a program, and the computer follows them to produce an output.

Problem
→
Instructions
→
Program
→
Computer
→
Output
Real-world analogy: Think of a recipe. The recipe gives step-by-step instructions, while the person following the recipe is like the computer following a program.

2. What are Variables?

A variable is a named place used by a program to store information. A variable has a name and a value, and its value can be used or changed while the program runs.

int age = 20;
PartMeaning
intData type
ageVariable name
20Value
=Assignment

3. Purpose of Variables

Variables allow programs to store data, use data later, change values, perform calculations, and work with information provided by the user.

int age = 20; int score = 95; int numberOfStudents = 40;
If score changes from 95 to 100, a calculation or output using score can also change. This is why storing information in variables is useful.

4. High-Level vs Low-Level Programming Languages

High-level languages are designed to be easier for humans to read and write. Examples include C++, Python, Java, and JavaScript.

Low-level languages are closer to computer hardware. Machine language and assembly language are examples.

LESSON 2

Basic C++ Program Structure

Understand the purpose of each part of a simple C++ program.

Learning Objectives

  • Explain the purpose of #include <iostream>.
  • Explain using namespace std;.
  • Explain int main().
  • Use cout to understand output.
  • Describe the simple purpose of return 0;.

Basic Structure

#include <iostream> using namespace std; int main() { cout << "Hello, World!"; return 0; }

1. #include <iostream>

#include tells the preprocessor to include a library/header. <iostream> provides standard input/output functionality and is commonly used when working with cout.

#include <iostream>
→
Input/output functionality
→
Use cout

2. using namespace std;

std is the standard namespace. A namespace groups related names. With using namespace std;, you can write cout instead of std::cout.

Without the using directive

std::cout << "Hello";

With it

using namespace std; cout << "Hello";

3. int main()

main() is the starting point of a standard C++ program. Program execution begins at main(). The int indicates that main returns an integer value.

Program starts
→
main()
→
Statements execute
→
Program ends

4. cout

cout displays output. The << operator sends the value or text to cout.

cout << "Hello";

Output: Hello

cout << 25;

Output: 25

cout << "Age: " << 20;

Output: Age: 20

5. return 0;

In the basic program structure, return 0; ends main() and returns the integer value 0.

Remember: iostream → input/output functionality; std → standard namespace; main() → starting point; cout → displays output; return 0; → ends main() with 0.

1. What are Data Types?

A data type tells the computer what kind of data a variable will store.

2. Basic C++ Data Types

int

Whole numbers.

int age = 20; int score = 95;

char

A single character.

char grade = 'A';

'A' is a character; "A" is text.

string

Text or a sequence of characters.

string name = "Steven";

Commonly used with #include <string>.

float

Decimal numbers using single-precision floating-point representation.

float temperature = 36.5;

double

Decimal numbers with greater precision than float.

double price = 99.99;

bool

Boolean values: true or false.

bool isStudent = true;

3. Rules for Declaring Variables

  1. A variable name can contain letters, numbers, and underscores.
  2. A variable name cannot start with a number.
  3. Variable names cannot contain spaces.
  4. Variable names cannot use reserved C++ keywords.
  5. C++ variable names are case-sensitive.
  6. Use meaningful variable names.

✓ Valid

int age; int studentAge; int student_age; int age2;

✗ Invalid

int 2age; int student age; int int;

2age starts with a number; student age has a space; int is a reserved keyword.

Remember: char uses single quotes, such as 'A'. Text strings use double quotes, such as "A" or "Hello". C++ variable names are case-sensitive.

5. Increment and Decrement

++ Increment

Increases a value by 1.

x++; ++x;

-- Decrement

Decreases a value by 1.

x--; --x;

6. Pre-Increment and Post-Increment

Post-increment: x++

int x = 5; int y = x++;

Use first: y gets 5.
Change second: x becomes 6.

Final: x = 6, y = 5

Pre-increment: ++x

int x = 5; int y = ++x;

Change first: x becomes 6.
Use second: y gets 6.

Final: x = 6, y = 6

7. Pre-Decrement and Post-Decrement

Post-decrement: x--

int x = 5; int y = x--;

Final: x = 4, y = 5

Pre-decrement: --x

int x = 5; int y = --x;

Final: x = 4, y = 4

Pre: change first, use second.
Post: use first, change second.

++x → change first, use second
x++ → use first, change second
--x → change first, use second
x-- → use first, change second
